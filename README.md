<h1>Anna's Archive Android</h1>

<p>
A modern Android application built with Kotlin and Jetpack Compose for searching, exploring and downloading books through a clean and intuitive interface.
</p>

<p>
Una aplicación Android moderna desarrollada con Kotlin y Jetpack Compose para buscar, explorar y descargar libros mediante una interfaz limpia e intuitiva.
</p>
</div>

<hr>

<h2>English</h2>

<h3>Overview</h3>

<p>
Anna's Archive Android is an open-source Android application inspired by Anna's Archive and built around the idea that knowledge should be accessible to everyone.
</p>

<p>
The project aims to provide a more modern, minimalistic and user-friendly mobile experience for searching and downloading books directly from Android devices.
</p>

<p>
Built entirely with Kotlin and Jetpack Compose, the application focuses on performance, usability and simplicity while maintaining a clean and scalable architecture.
</p>

<hr>

<h3>Search and Discovery</h3>

<p>
Users can search for any book through a simple and intuitive interface designed for fast navigation.
</p>

<ul>
<li>Fast book searching.</li>
<li>Modern Android user interface.</li>
<li>Pagination support.</li>
<li>Book discovery through filters.</li>
<li>Additional filters planned for future versions.</li>
<li>Smooth and responsive user experience.</li>
</ul>

<h2>Español</h2>

<h3>Descripción</h3>

<p>
Anna's Archive Android es una aplicación Android de código abierto inspirada en Anna's Archive y basada en la filosofía de que el conocimiento debe ser accesible para todos.
</p>

<p>
El proyecto busca ofrecer una experiencia más moderna, minimalista y amigable para buscar y descargar libros directamente desde dispositivos Android.
</p>

<p>
Desarrollada completamente con Kotlin y Jetpack Compose, la aplicación prioriza el rendimiento, la facilidad de uso y una arquitectura limpia y escalable.
</p>
